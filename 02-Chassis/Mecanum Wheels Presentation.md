# Mecanum Wheels Presentation (23 slides, with animations)

This deck covers how mecanum wheels move, simple trigonometry for driving at any angle, driving on curves, normalising wheel powers, step-by-step calculations, the Java code for robot-centric and field-centric drive, and testing. The last slides show our V3 shooter and a short testing clip.
